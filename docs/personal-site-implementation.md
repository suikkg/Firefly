# Firefly 个人站改造与验收记录

实施日期：2026-10-02。依据上一阶段完整审查方案实施，当前改动保留在本地工作区，未提交、推送或部署。

## 交付结果

网站统一为「KK · 通信与自动化工作札记」。主导航收敛为文章、生活、关于，搜索常驻。采用薄荷绿、深绿文字、系统中文字体与少量流萤插画，取消整屏壁纸、双侧栏和外观设置面板。浅色、深色和跟随系统通过一套主题逻辑管理。

首页突出两篇公开精选、LTE PHY 系列、主题入口和真实最新文章。文章使用独立阅读宽度、桌面文字目录、手机折叠目录、前后篇、必要许可说明和相关内容。六篇日志字典按系列顺序组织，避免同一天发布时目录次序混乱。

## 路由处理

- `/classic/` 与 `/classic/2/` 跳转到对应正式首页，旧第 3 页转归档。
- 真实旧文章链接跳转到对应 `/posts/*`；已退出正式内容的示例不生成无关首页跳转。
- `/sponsor/` 跳转到 `/about/#支持`。这是静态跳转页，未声称托管服务器已配置 HTTP 301。
- 分类、标签、归档、RSS、留言、相册、两种片单页面继续可访问。
- 内嵌评论页设置 noindex，旧版、内嵌评论与跳转页退出 sitemap；关闭的功能转 `/404.html`。

## 验证边界与使用

未执行评论提交、第三方登录、音乐完整播放、真实支付、线上重定向配置或部署；这些依赖外部服务。第三方图片及平台服务可用性仍取决于网络。未对线上 LCP 等性能指标做测量。

使用 Node >=22.12，推荐 Node 24。日常使用 `pnpm dev`；生产验证使用 `pnpm check`、`pnpm type-check`、`pnpm build`。全文搜索需要构建生成 Pagefind，开发模式会明确提示索引状态。`pnpm verify-site` 可单独复查现有 `dist`。

Pagefind 接入已通过 Context7 与官方文档交叉核对：[索引范围](https://pagefind.app/docs/indexing/)、[搜索 API](https://pagefind.app/docs/api/)。
