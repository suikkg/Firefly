# KK 信号札记：完整设计与实施方案

> 2026-10-03 后续修正：用户明确博客不只记录通信协议。整体身份与过量介绍已按 [博客定位与文案精简](blog-positioning-revision.md) 调整，本文作为上一阶段设计记录保留；当前品牌为 KK 的个人博客。

日期：2026-10-03。用户选择：清晰克制，有工程感和个人温度。基于当前工作区实施，保留已有个人站迁移成果。

## 定位与原创性

用「在信号与日常之间，留下一点记录」连接真实的通信协议、排障与自动化内容，以及相册、音乐和生活兴趣。网站的主要任务是帮助访客理解 KK 写什么、找到可读的笔记、沿系列继续研究。

记忆点集中在首页的原创「信号轨迹」：散乱的观测点汇入一条有节奏的曲线，配有协议 / 排障 / 自动化三个可切换视图。它是内容导航与概念插画，不伪装成实时仪表。采用原生 SVG/CSS 实现，布局和视觉资产独立设计。

审查中否决了大壁纸、整页等宽日志、黑底荧光色、重复的封面卡片、虚构活动热力图和在线状态。保留技术感，避免把个人博客做成监控后台。开源框架和原站署名继续保留，视觉原创不等于隐去来源。

## 设计系统

| 名称 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| 雾蓝 | `#F4F6FB` | `#121B2D` | 全站底色 |
| 白瓷 | `#FFFFFF` | `#1B2840` | 阅读和控件承载面 |
| 墨蓝 | `#202D46` | `#E8EDF8` | 主文字 |
| 蓝灰 | `#5A6880` | `#A8B7D0` | 次级信息 |
| 钴蓝 | `#3459D1` | `#A0B7FF` | 链接、焦点与信号主线 |
| 鸢尾 | `#ABA9E2` | `#9692D5` | 信号辅助轨迹 |

边界线浅色 `#DCE2ED`、深色 `#35455F`。浅蓝承载面 `#EAF0FD`。少量杏色仅用于生活图形，不用于低对比度正文。

正文使用 PingFang SC / Microsoft YaHei / 系统 sans-serif；标题同家族，以字重、留白与两行构图形成个性。英文图形字使用 Georgia 衬线作为一处视觉签名；等宽字体仅用于时间与图示刻度。桌面标题约 56px，手机约 36px；文章正文桌面 18px / 手机 16px，行高 1.9，内容宽度约 720–780px。

全站最大宽度 1160px，桌面左右 gutter 48px，手机 20px。8px 间距基准。基础圆角 12px、按钮 8px；仅信号画板使用不对称大圆角，层级由布局与承载面体现。焦点明确，按钮触控面积至少 44px，尊重 reduced-motion。

## 页面与信息架构

主导航：札记（现有归档路由）、生活、关于；搜索和三种主题常驻。首页品牌返回首页。增加全站 Ctrl/Cmd+K 搜索快捷键，输入时不拦截。

```text
桌面首页
┌ 品牌 / 札记 · 生活 · 关于                   搜索 / 主题 ┐
│ 个人介绍、大标题、入口          原创可切换信号轨迹       │
│ 协议笔记             故障分析             自动化工具    │
│ 从这两篇开始：信号测量文章          故障链路文章         │
│ 最近写下的记录（约 2/3）       KK 的边栏（约 1/3）      │
│ 分类筛选 + 真实文章列表        LTE PHY 系列、生活与联系  │
└ 简短个人签名                                  订阅等 ┘

手机首页
品牌 / 搜索 / 主题 → 导航 → 介绍 → 信号轨迹 → 方向入口
→ 精选 → 筛选与文章 → 系列及生活 → 页脚
```

首页只有一个 h1。首屏使用真实名称与内容定位；文章和分类计数构建期计算。置顶仍遵循现有内容配置。首页分类筛选当前页，计数显示当前分页范围，并提供全量归档入口；URL 支持链接与刷新恢复。没有 JavaScript 时仍能读所有文章并进入分类归档。

精选为两种不同内容构图：RSRP 测量标尺、T300 事件链。图形依据文章主题表达，不提供虚构测量。标题、描述、链接使用正式内容数据。

归档保持年分组、URL 标签/分类筛选和全量笔记，增加易识别的当前筛选状态；文章阅读保持独立宽度和桌面目录 / 手机折叠目录，增加阅读位置恢复、复制链接与字体舒适度控件。受保护文章解锁后才能记录正文阅读进度，持久化仅保存公开标题、路由和位置，不保存密码、正文或密文。

生活页以「工作之外」为主题，用不同大小的入口承载相册、音乐与近况；无数据的近况保持真实空态。关于页增加个人铭牌和内容方向，再呈现已有介绍、联系、支持和开源署名。
