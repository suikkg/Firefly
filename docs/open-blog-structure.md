# 随兴趣写的个人博客：结构调整

日期：2026-10-03。用户明确博客涵盖各种主题，随兴趣写，不固定分类。用户提供 RSRP 文章页作为参考。

## 完整方案

已检查文章与首页：文章页标题、正文、表格、目录属于具体内容，可用于其它文章；首页仍固定两篇技术推荐、LTE 大字典和波形标识，导致全站的内容身份过窄。本轮调整结构与视觉，不改专业文章正文。

- 首页变为紧凑的个人题签加时间文章流，取消半屏波形、固定两篇推荐、LTE 专属大卡与首页分类栏。所有主题共用时间流，分类和标签作为可选查找方式。
- 首页旁栏仅保留继续阅读、通用探索入口、生活与联系方式。不宣称主题范围，不虚构新文章。
- 导航使用“文章 / 生活 / 关于”。页头、关于铭牌、favicon 和分享图以 KK 字形作为身份，消除通信波形标识，保留雾蓝 / 钴蓝、原排版和字体签名。
- 新增通用专题索引，现有 LTE 系列作为一个真实专题；未来可加入其它专题。现有六篇的顺序和详情链接保持有效。
- 文章页继续使用通用阅读布局，真实分类、标签和内容照常显示，不把文章主题用作全站身份。
- 首页旧 `?topic=` 入口提供到对应归档筛选的原生链接；不再只筛当前分页而造成类别内容不全。
